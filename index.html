Hosting on GitHub & Features

GenCode Studio is engineered as a standalone web application packaged in a single index.html.

How to publish on GitHub Pages:

  1. Create a new repository on GitHub (e.g., gencode-studio).
  2. Upload or commit this file as index.html.
  3. In your repository, go to Settings > Pages.
  4. Set Branch to main, folder to / (root) and click Save.
  5. Your AI coding studio is live for the world at https://<username>.github.io/gencode-studio/!

Key Highlights:

  • Live Sandbox: Code runs immediately in an interactive sandbox.
  • Voice Prompting: Tap the microphone icon and speak your requirements.
  • Export Repo: Packages your synthesized code with a customized README and metadata into a ready-to-commit ZIP.
